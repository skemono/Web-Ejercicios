# Laboratorio 4: Cerdito de Angry Birds con CSS 🐷

¡Bienvenido al Lab 4!  
En este laboratorio aprenderás a replicar el famoso cerdito verde de **Angry Birds** usando únicamente **HTML** y **CSS**. El reto consiste en construir el cerdito utilizando solo `div`s y estilos CSS, sin imágenes externas (excepto la referencia).


## Estructura del proyecto

```
.
├── assets/
│   └── smallpig.png      # Imagen de referencia
├── index.html            # Estructura HTML
├── styles.css            # Estilos CSS para el cerdito
└── README.md             # Este archivo
```
